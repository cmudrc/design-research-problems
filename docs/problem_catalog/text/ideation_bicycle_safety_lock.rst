Statement
---------

Design a safety lock for a bicycle that is to be permanently fastened to it (not to be removed when being used). The lock is to be a lasting accessory, yet can still be removed or adjusted if necessary. It should be small enough to be non-obtrusive to the bicyclist while riding and should be light weight and relatively inexpensive.
