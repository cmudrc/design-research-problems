API
===

The top-level package exports a small curated public API:

- ``Citation``
- ``GrammarProblem``
- ``MissingOptionalDependencyError``
- ``OptimizationProblem``
- ``ProblemAsset``
- ``ProblemEvaluationError``
- ``ProblemKind``
- ``ProblemMetadata``
- ``ProblemRegistry``
- ``ProblemTaxonomy``
- ``TextProblem``
- ``get_problem``
- ``list_problems``

See :doc:`reference/index` for the module-level reference pages.
