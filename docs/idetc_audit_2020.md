# IDETC 2020 Ideation Audit

Working notes for auditing `conferences/2020 IDETC/` against
`src/design_research_problems/_assets/ideation/catalog.toml`.

## Scope

- Goal: identify IDETC 2020 papers that expose reusable ideation prompts,
  task briefs, or participant-facing study materials not yet captured in the
  ideation catalog.
- Focus:
  - participant-facing design prompts, including concrete educational briefs
    when the paper prints a stable problem statement
  - appendix, methods, or workshop materials that expose reusable task wording
  - prompt lineage that materially adds new families rather than only
    reiterating already-captured tasks
